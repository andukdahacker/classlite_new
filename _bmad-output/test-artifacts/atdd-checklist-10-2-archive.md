## WF-8 posture

## GREEN-PHASE SEAM CONTRACT (what the dev builds; the reds compile/run against these)

### Backend — the compile seam

`service.NewArchiveService(db, clk)` + `handler.NewArchiveHandler(svc, clk)` + `(*ArchiveHandler).List(w,r) error` wired at `GET /api/archive` on the staff-gated chain (owner/admin/teacher). Transitively requires:

1. **migration** `{next}_add_classes_ended_at` — `classes.ended_at timestamptz` (additive, nullable); stamped `= @now` on the `→ended` branch of `UpdateClassStatus` (keep the CAS `WHERE status=@expected` guard + the `class.status_changed` audit); genesis-backfill existing `status='ended'` rows (latest `class.status_changed→ended` audit ts, else `updated_at`). `down` drops the column.
2. **sqlc** `internal/store/queries/archive.sql`:
   - `ListArchive :many` — `UNION ALL` of (a) archived exercises `WHERE e.deleted_at IS NOT NULL AND (@teacher_id::uuid IS NULL OR e.created_by=@teacher_id) AND (@type_filter='' OR @type_filter='exercise')` projecting `'exercise' AS type, id, title, …, deleted_at AS archived_at, NULL AS class_status, skill, target_band` and (b) archived classes `WHERE c.status='ended' AND c.ended_at IS NOT NULL AND c.ended_at <= @cutoff AND (@teacher_id::uuid IS NULL OR c.teacher_id=@teacher_id) AND (@type_filter='' OR @type_filter='class')` projecting `'class', id, name AS title, …, ended_at AS archived_at, status, NULL, NULL`; outer `ORDER BY archived_at DESC, id DESC LIMIT @lim OFFSET @off`. Common projected column list/types across both branches.
   - `CountArchive :one` — `SELECT count(*) FROM (…the two WHEREs unioned…)`.
   - `sqlc generate` → `generated.ListArchive/CountArchive` + params/rows.
3. **service** `(*ArchiveService).List(ctx, tc model.TenantContext, f ArchiveListFilter{Type string; Page, PageSize int}) ([]ArchiveItem, PageResult, error)` — `clampPagination` + `math.MaxInt32` page/offset overflow guards; role-branch `teacherID = &tc.UserID` for `RoleTeacher`, else nil (owner/admin center-wide); **`RoleStudent` → `ForbiddenError` (403)**; validate `Type ∈ {"","class","exercise"}` else `ValidationError` (→422); `cutoff := clk.Now().Add(-archiveClassGraceDays)` (`archiveClassGraceDays = 30*24h`, named const CQ-3); ONE `readInTenantTx`; build each exercise item's `link = /exercises/{id}/edit`; `pageResult(page,pageSize,total)`.
   - `ArchiveItem` DTO: `{Type, ID, Title, Subtitle string; ArchivedAt *string/*time; ClassStatus, Skill *string; TargetBand *int; Link string}` — explicit `json` tags, **no `omitempty`** (GO-5); per-type fields nullable.
4. **handler** `List` — tenant extractor → `parseSnakePageParams` → read `type` query param → `now := h.clk.Now()` → `svc.List(...)` → `writePaginatedEnvelope(w, h.clk, items, pageMeta)`.
5. **route** `cmd/api/main.go`: `GET /api/archive` on the staff chain; **api.yaml** `ArchiveItem` + `EnvelopeArchiveList` (`{data:[ArchiveItem], meta: EnvelopeMetaPagination}`) + the path (params `page`,`page_size`,`type`; 422 ErrorEnvelope) → `scripts/codegen.sh`.

The test parse structs (`arItem`/`arEnvelope` in `story_10_2_helpers_test.go`) expect camelCase JSON: `type, id, title, subtitle, archivedAt, classStatus, skill, targetBand, link` + `meta.pagination.{page,pageSize,total,totalPages}`.
