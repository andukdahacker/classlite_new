### Falsifiable-core design notes
- **jsdom has no SVG layout** — chart tests assert on EXPLICIT attributes the component sets from the pure scale fns (`data-bucket`, `data-x`, `data-y`, `<line y1>`), never on computed geometry. This is what makes them un-fakeable by a lazy "it rendered" impl.
- **AC22f target-line** uses an exact assertion: a data point at band === targetBand must plot at the same y as the target `<line>` (proves same y-scale, not pinned/raw), and a lower band sits below it (proves real inverted scaling).
- **AC22a monotonicity** is asserted via the exported `heatmapCellStyle` FN (ordering, not hex) AND re-asserted through the rendered `data-bucket` — tying component to fn.
- **AC22 query-shape resolution:** `ClassPerformance` is ONE aggregate GET, so the trilogy is loading-skeleton / whole-view-500-error+retry / per-sub-collection empties. There is NO partial-failure surface (documented in-file).
