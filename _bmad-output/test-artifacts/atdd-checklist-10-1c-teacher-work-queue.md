## GREEN-PHASE SEAM CONTRACT (what the dev builds; the reds compile/run against these)

### Backend — the ONE compile seam

`handler.(*InboxHandler).TeacherQueue(w,r) error` wired at `GET /api/inbox/teacher-queue` on the ungated `questionChain`. Transitively requires:

1. **sqlc** `internal/store/queries/submissions.sql`:
   - `ListTeacherQueue :many` — clone of `dashboard.sql:28-49` `ListGradingBacklog` + add `sub.is_late`, `c.id AS class_id`, `a.id AS assignment_id`; replace `LIMIT item_limit` with `LIMIT sqlc.arg('lim') OFFSET sqlc.arg('off')`; add `AND (NOT sqlc.arg('late_only')::bool OR sub.is_late)`; keep `(COALESCE(a.hard_deadline_at,a.deadline_at) < sqlc.arg('now'))::bool AS overdue` and `ORDER BY sub.submitted_at ASC NULLS LAST, sub.id ASC`. `teacher_id` is a REQUIRED arg (not narg) bound to the caller (Ducdo Q4).
   - `CountTeacherQueue :one` — same WHERE incl. `late_only`.
   - `sqlc generate` → `generated.ListTeacherQueue/CountTeacherQueue` + params/rows.
2. **service** `(*NotificationService).ListTeacherQueue(ctx, tc, lateOnly bool, now time.Time, page, pageSize int) ([]TeacherQueueItem, PageResult, error)` — mirror `ListInbox` (`notification_service.go:551-611`): `clampPagination` + `math.MaxInt32` page/offset overflow guards; ONE `inTenantTx`; `teacherID := tc.UserID` bound to List + Count; build `link = /classes/{classId}/grading/{assignmentId}/{submissionId}` server-side; return `pageResult(page,pageSize,total)`.
   - `TeacherQueueItem` DTO: `{SubmissionID, StudentName, AssignmentTitle, ClassName string; IsLate, Overdue bool; SubmittedAt *time/*string; ClassID, AssignmentID, Link string}` — explicit `json` tags, **no `omitempty`** (GO-5).
3. **handler** `TeacherQueue` — `requireQuestionTenant` → `parseSnakePageParams` → parse `late_only` bool → `now := h.clk.Now()` → `svc.ListTeacherQueue(...)` → `writePaginatedEnvelope(w, h.clk, items, pageMeta)`.
4. **route** `cmd/api/main.go`: `mux.Handle("GET /api/inbox/teacher-queue", questionChain(inboxHandler.TeacherQueue))`.
5. **api.yaml**: `TeacherQueueItem` + `EnvelopeTeacherQueueList` (`{data:[TeacherQueueItem], meta: EnvelopeMetaPagination}`) + the path (params `page`,`page_size`,`late_only`) → `scripts/codegen.sh`. **No migration** (derived read over existing tables).

The test parse structs (`tqItem`/`tqEnvelope` in `story_10_1c_helpers_test.go`) expect camelCase JSON: `submissionId, studentName, assignmentTitle, className, isLate, overdue, submittedAt, classId, assignmentId, link` + `meta.pagination.{page,pageSize,total,totalPages}`.
