## Story

As a **teacher deciding whether to trust an AI band score** (and as Ducdo, carrying the product's one unmeasured value claim into the L1 pilot),
I want **the shipped grader's output measured against real examiner judgement on a frozen set of IELTS samples — band accuracy, re-grade stability, rubric-criteria coverage, and feedback safety — with a Vietnamese teacher rating the feedback's usefulness**,
so that **I am not doing double work reading a plausible-but-wrong grade and regrading by hand, and a Gemini model revision that silently regresses grading is caught by a machine rather than by a parent.**

**Product evidence, not QA.** This story does **not** change grading behavior, ship an endpoint, add a migration, or touch `api.yaml`. It builds a **calibration harness** that drives the *existing, unmodified* 6-2a writing / 6-3b speaking grade path against a **frozen gold set** and asserts the four R5 machine assertions, plus a VN-teacher usefulness rating captured as a product-evidence artifact.

**Done when** (epic-11.md:533): Gemini's bands sit within the agreed tolerance of examiner bands across the set, a deliberately perturbed grade is caught, and a Vietnamese teacher has rated the feedback's usefulness. (See DD5/DD1 for how merge-time scope splits the mechanism from the first real-data run.)

### Net-new — THIS story builds (all under `classlite-api/internal/calibration/`, a new leaf package — CQ-4 single lowercase word)

- **`goldset.go`** — gold-set schema + loader. Structs: `GoldSample{ID, Skill (writing|speaking), TaskType, Source (cambridge|idp|center), ExaminerOverall float64, ExaminerCriteria map[string]float64, Language, ContentRef}` and a `Manifest` of samples with a content hash per sample (the "frozen" guarantee). Loader reads from a configurable dataset dir (DD2) and falls back to the committed synthetic anchors (`testdata/`). No raw student content ever enters a committed file.
- **`assertions.go`** — the four R5 machine assertions as **pure exported functions over a graded sample** (plain Go, stdlib + hand helpers — house style, no testify):
  - `BandAccuracy(ai, examiner float64, tol float64) (delta float64, pass bool)` — |AI overall − examiner overall| ≤ tol (DD5 tolerances).
  - `Stability(bands []float64, tol float64) (maxSpread float64, pass bool)` — N re-grades of one sample land within tol.
  - `CriterionCoverage(skill string, result any) error` — every criterion key present, band passes `ValidateCriterionScores`, rationale non-empty, confidence ∈ {high,medium}, in the requested `Language`.
  - `FeedbackSafety(feedback, piiProbes []string) (findings []string)` — **PII (gated):** value-scan the feedback/comment text for the sample's known name/email/phone probes (value-scan, never key-scan — the stripped-field null trap). **URL/domain (gated):** the grader should never emit a link; a crisp, low-false-positive check. **Fabricated citation is NOT a gated regex** (Murat R5 — "according to"/quoted-source flags good feedback that quotes the student's own sentence, and misses "Research shows…"); it is surfaced as a **sample for human review** in the usefulness pass, not a machine gate.
- **`report.go`** — report rendering is a **plain exported function returning a structured report** (Winston — so a future `tools/calibrate` binary is a trivial `main` calling this package; the logic is NOT buried in test bodies). It writes a band-delta table (per-criterion + overall), per-band-bucket MAE, worst-miss + over-score direction, stability spreads/stddev, and pass/fail to `_bmad-output/test-artifacts/calibration/calibration-report-<date>.md`. `<date>` passed in, never `time.Now()` (determinism).
- **`assertions_test.go`** (UNTAGGED — CI-green, no Gemini, no DB) — the **perturbation self-test (AC5)**: feed synthetic anchor results, assert each assertion PASSES on a correct grade and FAILS on a deliberately perturbed one (+2 band offset, blanked criterion, injected PII, fabricated citation). ### Design decisions pinned (engineering calls — override at dev pickup only with a written reason; the four Ducdo forks are saved to the end of this story)

- **DD1 — The harness drives the REAL grader; it never reimplements the prompt or the parse.** The shipped prompt lives inside `buildWritingGradePrompt`/`buildSpeakingGradePrompt`. Measuring a re-typed prompt measures a different grader and the calibration is worthless. The harness seeds a submission and runs the real `GradeWritingHandler`/`GradeSpeakingHandler` with the real `gemini.Client`. Zero new grading logic.
- **DD2 — Gold-set data: synthetic anchors committed; real data EXTERNAL + hash-manifested (R-11-6 + copyright).** Published Cambridge/IDP samples are copyrighted and the center's own submissions are **real student work (minors)** — neither may be committed to the repo. Committed: the schema + a small synthetic anchor set (mechanism only). Real data lives at `CALIBRATION_DATASET_DIR` (gitignored); a committed `manifest.json` carries examiner bands + metadata + per-sample content **hashes** (the "frozen" guarantee) but **no raw content/PII**. The harness **verifies each sample's hash against the manifest at run start** — a silently-mutated local dataset is a HARD ERROR, never a quiet re-baseline (Murat). Harness LOUD-SKIPs when the dataset is absent.
- **DD3 — Result-capturing seam: thin read-only accessor PRIMARY (Winston; flipped from the drafted default).** `JobHandler.ProcessTask` returns only an error; `ProcessSpecific` never persists `job.result`, so the harness needs the result fragment by another path. **The fragment the grader produces IS the measurement target; persisting it to `job.result` is a *dispatcher* concern, and calibration grades the grader, not the dispatcher.** So: a **thin read-only exported accessor** on the handler returning the already-computed fragment reads exactly the artifact under test, at its source, with nothing to drift. Do NOT replay the dispatcher's `MarkJobComplete` choreography inside the shared `internal/test/workers` harness — that re-assembles production orchestration in a test helper (drift risk) and widens a shared helper's blast radius for a concern only calibration has. **Cover the serialize→persist→deserialize round-trip separately** with ONE cheap UNTAGGED dispatcher test asserting `handler fragment == what lands in job.result` — don't make the expensive real-Gemini run also be your serialization regression test. Never assert off `ProcessSpecific` alone — it discards what you need.
- **DD4 — Writing gets the full real-data path now; speaking is wired but its dataset is DEFERRED.** Writing samples are plain text — clean, no licensing/size/ffmpeg burden. Speaking needs real audio objects in R2 + ffmpeg + larger copyrighted recordings. The harness, loader, and assertions are **skill-generic** (handle both), but the committed anchors + the first real run cover **writing**; speaking is schema-ready and LOUD-SKIPs until an audio dataset is assembled (tracked in manual-setup).
- **DD5 — Pinned tolerances — per-criterion is the HARD gate, not the aggregate (Murat R1/R2/R3 + Mary).** The overall band averages four criteria, so **compensating errors cancel** (+1.0 on one criterion, −1.0 on another → a perfect overall). The per-criterion band is the product teachers read, so it gates:
  - **Accuracy (hard gate): `PerCriterionTol = 1.0`** — every criterion band within 1.0 of the examiner's (±1.0 is already generous: human examiners disagree ~0.5/criterion). `OverallBandTol = 0.5` is a **secondary** check, not the gate. Additionally report **worst single-criterion miss** and the **direction** of overall misses — over-scoring a weak student is commercially lethal in a way under-scoring is not (Mary); a named `WorstMiss`/`OverScoreRate` in the report.
  - **Stability (hard gate): `StabilityReGrades = 5`** (NOT 3 — range-of-3 is a biased-low spread estimator that passes while the grader is visibly unstable, Murat R1); assert on **per-criterion regrade range ≤ 1.0 AND overall-band stddev ≤ 0.25**, not just max pairwise spread. **Pin + record the grading `temperature`** the shipped worker sends in the captured metadata (dev Task: find what `GradeWritingHandler` → `gemini.GenerateRequest` actually sets; justify the tolerance against it).
  - **MAE: an ABSOLUTE floor, separate from a DRIFT tripwire (Murat R3).** `MaxAcceptableMAE` is an examiner-truth quality floor (~0.5, from IELTS inter-rater reality) and is the DONE gate — it is NOT derived from our own first run. A separate run-to-run MAE-delta is a **warn/investigate drift signal** (the model-revision tripwire), never a green/red gate — else Gemini bumping the model silently re-baselines quality.
  - All named consts (CQ-3); override with a written reason.
- **DD6 — VN feedback does NOT exist; the rating is a PARENT-VETO, not a score (recon + John + Mary).** Both prompts are **English-only** — no locale toggle anywhere in `internal/worker`/`internal/gemini`/`internal/config`. The product emits **zero Vietnamese output**, so the artifact is honestly titled **"English-feedback usefulness to a bilingual teacher"** — NOT "VN feedback to a student" (a band-4 teenager cannot necessarily read band-7 English feedback *about their band-5 English*; the signal routes through the one fluent adult in the room — Mary). The rating is **not a numeric score** (n=1 scored is theater — John); it is a **binary veto with a reason**: *"would you let this feedback go home to a parent — yes/no, and if no, why?"* One honest "no" is a smoke detector worth more than any 5-point average. The real gap — *the product produces no Vietnamese output* — is filed as **FU-11-0B-VN-FEEDBACK** and named plainly as a deferral of the product, not of polish. Do NOT add a VN prompt directive in this story.
- **DD9 — The gold set's OWN banding must be calibrated — you cannot trust a grader against a ruler nobody checked (Mary + John, the #1 convergent finding).** The center teacher who bands the commercially-critical bands-4-6 cohort is **not a certified examiner**, and the published half (bands 7–8) and the center half (4–6) cover **different ranges**, so they never band the same scripts and the "examiner = escalation on disagreement" safety net rarely fires. Required: an **overlap zone** — a handful of 4–6 scripts banded by **both** the center teacher **and** the certified examiner — with a reported **inter-rater agreement** on those anchors. A tight tolerance against a crooked ruler is precision in service of a lie (John). The gold set is only admissible evidence once its own banding has an inter-rater check.
- **DD10 — Real worker + real DB + real Gemini = three flake sources; transport failure ≠ grade-wrong (Murat R6).** The calibration run must (a) treat a Gemini **429 / network / timeout as a distinct exit state** (retry-with-backoff, then "transport failure", NEVER reported as a quality red); (b) isolate per-run job rows so two runs don't contaminate each other; (c) because the grader is non-deterministic, treat **the accuracy run itself as a sample** — the DONE run reports a **confidence interval or runs K times**, not a single draw (MAE 0.48 against a 0.5 floor on one run is a coin flip on green/red); (d) carry a documented cost/time budget. These keep the rare, manual, must-be-trustworthy run from lying on a single invocation.
- **DD7 — DONE requires the REAL calibration run to pass — story stays WHOLE, held in `review` [Ducdo rulings 2026-10-12, incl. party-mode fork A].** The mechanism (AC5 teeth-matrix + AC6 coverage/safety green against synthetic anchors) lands first but is **NOT a sufficient done bar**. The story is **not split** into a separate 11-0c — it is kept whole and **held in `review`** (knowingly, through the pilot if need be) until the real run passes. Two real-data milestones (fork B):
  - **Interim (pre-pilot capable, NOT done):** the **published Cambridge/IDP anchor** run passes — an early confidence checkpoint recorded in the report. Treat it as a *sanity anchor*, not proof: these samples skew to bands 7–8 and are plausibly in the model's training data, so a pass here is necessary-not-sufficient and mildly flattering.
  - **Authoritative (the DONE gate, matures THROUGH the L1 pilot):** the **bands-4-6 center-banded** cohort — where real students actually sit and where ±0.5 is commercially load-bearing — graded within tolerance (AC1 per-criterion), stable (AC2), with its own banding inter-rater-checked (AC9), plus the AC7 parent-veto. This cohort is a **pilot byproduct** (the submissions don't exist until the pilot generates them), so it is assembled continuously through the pilot; 11-0b closes to `done` only when this authoritative run passes.
  - `dev-story` builds the full harness + mechanism → `review`. The story **cannot transition to `done`** until Ducdo assembles the dataset (manual toil tracked in `manual-setup.md`), sets `GEMINI_API_KEY`, and the authoritative `-tags=calibration` run passes. Closure is deliberately coupled to examiner-scored evidence — a green mechanism is not proof the grader is right.
- **DD8 — This story does NOT build 11-4's human rubric.** 11-4 consumes this gold set and adds the double-score sample-size/agreement measure + the role-visibility grid (epic-11.md:755). Here: the gold set + the four machine assertions + ONE VN-teacher usefulness rating. No agreement-measure machinery.

## Acceptance Criteria (BDD)

### AC1: Band accuracy vs examiner — PER-CRITERION gated, stratified by band [R5(a); real-data run — DONE-REQUIRED, DD5/DD7]
Given the frozen gold set loaded from the dataset dir and a real `gemini.Client` (`GEMINI_API_KEY` set),
When each writing sample is graded through the **real** `GradeWritingHandler`,
Then the **hard gate is per-criterion**: every criterion band is within `PerCriterionTol (1.0)` of the examiner's (the overall-band ±0.5 via `grading.OverallBandFromFour` is a **secondary** check — averaging hides compensating per-criterion errors);
And the **authoritative pass/fail gate is the bands-4-6 center-banded cohort** (where real students sit; fork B); the published Cambridge/IDP anchors are an **interim sanity check only** (necessary-not-sufficient — they skew high and are plausibly in training data), reported separately and never sufficient on their own;
And the dataset meets a **minimum N stratified per half-band** across the range students sit (not a single total), and **MAE is reported per band bucket** plus the worst single-criterion miss and the over-score direction;
And the set-level MAE clears the **absolute examiner-truth floor `MaxAcceptableMAE` (~0.5)** — the DONE gate, NOT derived from our own first run — while a run-to-run MAE delta is a separate **drift warning**, never a green/red gate;
And a Gemini **429/network/timeout is reported as a transport failure (retried, then skipped), NEVER as a quality red**; the DONE accuracy run reports a **confidence interval or runs K times** (a single non-deterministic draw near the floor is a coin flip);
And when `GEMINI_API_KEY` or the dataset dir is absent, the run **LOUD-SKIPs** with a reason (CI stays green, no credits spent).

### AC2: Re-grade stability [R5(b) — CANNOT be skipped; DD5]
Given one gold-set sample,
When it is graded `StabilityReGrades (5)` times through the real grader,
Then **every criterion's regrade range is ≤ 1.0 AND the overall-band stddev is ≤ 0.25** (not merely a max pairwise spread over 3 draws — that passes while the grader is visibly unstable);
And the grading **temperature the shipped worker sends** is recorded in the captured metadata and the tolerance is justified against it;
And the per-criterion distribution is recorded, so a Gemini model revision that destabilises grading is a machine failure, not a parent's discovery.

### AC3: Rubric-criteria coverage [R5(c)]
Given a graded result (writing or speaking),
When `CriterionCoverage` runs,
Then every criterion key for that skill is present with a band that passes `grading.ValidateCriterionScores` (1.0–9.0, 0.5 grid), a **non-empty** rationale, a confidence ∈ {high, medium}, in the requested language;
And a missing criterion, an off-grid/out-of-range band, a blank rationale, or a bad confidence is a **coverage failure** naming the offending criterion.

### AC4: Feedback safety — PII + no-URL gated; fabricated-citation surfaced not gated [R5(d); DD5 FeedbackSafety split]
Given a graded result whose seeded submission carried known PII probes (a student name / email / phone),
When `FeedbackSafety` scans the feedback + comments,
Then none of the PII probes appear as a substring in any feedback/rationale/comment text (**value-scan, not key-scan**), and **no URL/domain pattern** appears — both are hard gates;
And a possible fabricated citation is **surfaced as a human-review sample**, NOT failed by regex (the heuristic has unstatable precision — gating it manufactures a false green);
And any finding is reported with the offending text located.

### AC5: A deliberately perturbed grade is CAUGHT — boundary mutation matrix [Done-when; assertions-have-teeth; UNTAGGED, CI-green, authored FIRST; DD5/Murat R4]
Given the synthetic anchor set (no Gemini, no DB),
When each assertion is run against a CORRECT grade, Then it PASSES;
And **each assertion has ≥1 passing-boundary mutant and ≥1 failing-boundary mutant, tuned to the threshold** (not a trivial 5-band-wrong mutant that proves nothing about the boundary that matters):
- Accuracy: a criterion off by **exactly 1.0 must FAIL**, off by **0.5 must PASS**;
- Stability: 5 regrades spanning **1.0 must FAIL**, spanning **0.5 must PASS**;
- Coverage: an empty-rationale result, a wrong-language result, and a null-band result each FAIL **independently**;
- Safety: a feedback blob with a student name FAILS, one with a `http://` URL FAILS;
So the harness cannot green-light a wrong grader (a vacuous-green harness is worse than none), and the assertions are proven independent rather than one masking a dead one.

### AC6: Frozen set + report are reproducible product evidence
Given the gold set,
When the mechanism runs,
Then each sample's content hash is **verified against the committed manifest at run start** (a mismatch is a hard error, not a silent re-baseline) and no raw student content or copyrighted sample is committed to the repo;
And a human-readable report is written under `_bmad-output/test-artifacts/calibration/` carrying **per-criterion AND overall** band deltas, **MAE per band bucket** (not just set-wide — a set-wide number is dominated by wherever anchors cluster), worst single-criterion miss, over-score direction, stability stddev, and pass/fail.

### AC7: A qualified teacher vetoes the feedback (parent-gate) [Done-when; real-data step — DONE-REQUIRED, DD6]
Given a sample of real graded feedback,
When a Vietnamese (bilingual) teacher reviews it,
Then a **binary veto with a reason** is captured — *"would you let this go home to a parent: yes/no; if no, why"* (NOT a numeric usefulness score — n=1 scored is theater);
And the artifact is honestly titled **"English-feedback usefulness to a bilingual teacher"** and names the limitation that the product emits no Vietnamese output;
And the VN-language-output gap is recorded against **FU-11-0B-VN-FEEDBACK**.

### AC8: Activation + procedure are documented (WF-9)
