## Story

As a Teacher or an Admin/Owner,
I want to see all my students with their performance data and drill into an individual student's profile with the teacher's notes,
so that I can monitor progress and identify the students who need attention — over the student backend shipped in 7-2a.

Frontend slice only. The role-scoped roster read, the whole-student detail composition (band / per-skill / attendance / submission stats / `currentVsFirstDelta`), the `AtRiskDetector` classification, and the notes CRUD were built + tested in **7-2a** and are already generated into `src/lib/api/client.ts`. This story is the **sole consumer** and per D13 **co-finalizes** the provisional read contract (mirrors 7-1b's D16 / 6-4b's contract co-finalization).

## Acceptance Criteria

### A. Route wiring + role gating (s42/s10a/s10)

1. **Given** a Teacher clicks "Students" in the sidebar, **When** `/students` resolves, **Then** the s10a teacher roster renders (the previously-dead link now routes) behind `RouteRoleGate allowedRoles={['teacher']}`. **And** an Owner/Admin/Student navigating to `/students` or `/students/:id` sees `<PermissionDenied>` with **staff-inclusive** section copy (the existing owner/admin-only `section.students.header` is broadened, or a teacher-worded key added — D1 denied-copy fix; a teacher-gated route must NOT show "available to owners and admins" / "owner"-worded copy).
2. **Given** an Owner or Admin, **When** `/people/students` resolves, **Then** the s42 center-wide list renders behind `RouteRoleGate allowedRoles={['owner','admin']}`; a Teacher/Student is denied. **And** a "Students" nav entry is added under the owner/admin "People" group in `sidebarNavConfig.tsx` (pointing at `/people/students`).
3. **Given** a student row click, **When** the detail resolves, **Then** the shared `StudentDetailPage` renders at `/students/:id` (teacher) or `/people/students/:id` (owner/admin), each deep-imported (its own chunk); a 404 `STUDENT_NOT_FOUND` renders a not-found state, not a crash. **And** `/students/import` (Story 2.7) still resolves — asserted by a route-precedence test (`:id` never matches `"import"`).

### B. s10a teacher roster (client-tab list, teacher-scoped)

4. **Given** the roster loads via `useQuery` → `apiFetchWithMeta<StudentListItem[]>('/api/students?page_size=100')`, **Then** the `teacher` variant renders columns: Student (avatar tile + name + email) · **My classes** (class chips) · Avg band (`overallBand`, bold, "—" when null) · **Attendance** (`—` never "0%" when the field is null) · Status (`PerfPill`) · Joined (mono date via the i18n formatter, TS-6). Rows show ONLY the caller-teacher's own-class students (backend-scoped, 7-2a D3) — asserted via MSW.
5. **Given** the tabs, **Then** All / At-risk / New / By-class render with mono client-side counts (`countByStatus` per D5); "By-class" groups rows by `enrolledClasses`; default tab = first with count > 0; the active tab is `aria-current`.
6. **Given** loading / empty / error (UX-1 trilogy, mandatory), **Then**: loading → row-shaped skeletons (never a centered spinner); empty → an informational empty-state shell (role-appropriate headline; **no** "invite/add" action — enrollment is Story 7.3, D14); error → an inline `role="alert"` with a retry that calls `refetch` (not a full-page error).

### C. s42 center-wide list (owner/admin variant)

7. **Given** the `center` variant, **Then** columns render per UX s42: Student · **Classes** (mono, e.g. "Writing 6.5 · Reading R60") · **Teacher(s)** (mono `teachers[]` distinct names) · Avg band · Status (`PerfPill`) · Joined. Admin/Owner see all `role='student'` members center-wide (backend-scoped).
8. **Given** the tabs, **Then** All / At-risk / New / Unassigned / Archived render with mono counts (D5); the page-head superscript shows "N enrolled · M at-risk · K unassigned".
9. **Given** an **unassigned** student (`activeEnrollmentCount===0`), **Then** the row shows the amber treatment (`??` avatar, "— unassigned" in accent-amber, Avg band "—", `PerfPill perf-unassigned`) per D12.
10. **Given** the roster `total > 100` (D6), **Then** the pager renders AND a `role="status"` note states counts reflect the loaded page (narrow via the class/teacher filter). **And** the class/teacher filter chips issue server-side `?class_id` / `?teacher_id` (never client-only filtering that breaks counts).

### D. s10 student detail (shared page — band / per-skill / attendance / submissions / deltas)

### E. Teacher notes (composer + chronological flag/log)

15. **Given** the `StudentNotesPanel` on s10, **Then** `useQuery` → `apiFetch<StudentNote[]>('/api/students/{id}/notes')` renders a chronological (ASC) log; each item shows `authorName` + `createdAt` (i18n formatter) + content; `flagged===true` → amber flag variant, plain otherwise (no red "warn" tier — unbacked, D11). 18. **Given** any note mutation is in flight, **Then** the triggering control is disabled during `isPending` (no double-submit).
