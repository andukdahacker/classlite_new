## Story

As a teacher, admin, or owner,
I want a student-performance detail at `/analytics/student/:id` with an Overview tab (per-skill band progression, per-skill breakdown, submission/pin stats) and a Mistakes tab (skill-filterable repetitive-mistake rows across all four skills, with the graded quote + teacher note + frequency),
and as a student I want a `/my-performance` view with an Overview tab and a **softened "Patterns"** tab that never uses "mistakes" language, never shows a class average or another student's data, and frames regression as a neutral focus-area — plus a "glance not work" mobile treatment and a "Share summary" affordance,
so that individual progress and recurring patterns are visible and actionable, and a student sees only a calm, encouraging view of their own data (FR-49, FR-50, UX-DR22, UX-DR25).

Mostly-frontend slice. The 8-3a backend already ships both endpoints, all scope/tenant/privacy enforcement (`/me` strips the peer fields **service-side**), and the generated `StudentPerformance` wire types (PROVISIONAL — this story co-finalizes them, D-COFINAL). This story is **UI + routing + i18n + a single WF-4 contract co-finalize**: build the teacher 2-tab detail + the real student 2-tab view (replacing the 8-2b placeholder), reuse the 8-2b/7-2b charts + primitives, add the reading|listening `skillSource` i18n (which also lights up the 8-2b class Mistakes tab), and ship the share summary. NO new endpoints, NO new business logic, NO mutations (analytics is read-only) — the ONLY backend touch is the D-COFINAL WF-4 field split (`analytics_service.go` populates the new `questionType`). The AI **Recommendations** tab is **Story 8.3c** — s47 ships as exactly **2 tabs**, NO coming-soon headstone (D2/8-3a-F2).
