## Story

As a teacher, admin, or owner,
I want an analytics home at `/analytics` that role-branches to the classes I'm allowed to analyze, and a class-performance view at `/analytics/class/:id` that renders the cohort's band-over-time trend, a Writing-criteria × week heatmap, repetitive-mistake rows, the at-risk list, and the on-time submission rate,
so that I can monitor class-level trends, spot weak criteria/weeks at a glance, and intervene early — and as a student I am cleanly redirected to my own performance view instead of hitting a screen that isn't mine.

Frontend slice only. The 8-2a backend already ships both endpoints, all scope/tenant enforcement, and the generated `Analytics*` wire types (PROVISIONAL — this story co-finalizes them, D1). This story is **pure UI + routing + i18n**: wire the pre-built 1d-4 `AnalyticsHomeShell`/`ScopeBar` shells, build the two net-new charts, reuse the dashboard/7-2b primitives, and register the student-redirect placeholder. NO new endpoints, NO backend logic, NO mutations (analytics is read-only). The real `/my-performance` page + `/api/analytics/me` are **Story 8.3** — this story registers only a minimal placeholder so the redirect never 404s.
