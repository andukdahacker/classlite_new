## Story

As a **student**,
I want **to reopen an assignment I've already submitted and calmly review exactly what I handed in — re-read my essay, see the answers I chose, and re-hear my speaking recording — with a clear note that grading hasn't been released yet**,
so that **the moment I submit I have a durable home to revisit my own work (I currently can never re-hear a submitted recording at all — the 5.4 D11 gap), instead of a dead end until a teacher grades it — and so this page is already the shell the graded result (5-5b) fills in later**.

**Scope:** Frontend "review my submission" page + TWO additive backend read endpoints. Desktop + mobile at **`/assignments/:assignmentId/submission`** (renamed from `/result` — D7/D12). Renders the student's OWN terminal submission read-only, with a quiet "grades not released yet" note (no grades exist — Epic 6 backlog). Backend: **`GET /api/assignments/{assignmentId}/result`** (endpoint name FROZEN as the 5-5b contract; student-owned; resolves the unique `(student, assignment)` submission; mirrors `GetAttemptBundle`'s ownership-404 + active-enrollment-403; NOT lock-gated; `in_progress` short-circuits to a resume-CTA payload; terminal → `released:false` + answer-stripped read-back + `submission.id` + inline first-paint `audioUrl`) **and** **`GET /api/assignments/{assignmentId}/submission/audio`** (on-demand fresh 5-min audio presign for play-intent — D8). Both share a new `StorageService.PresignGetOwned` SEC-8 primitive. **Out of scope → 5-5b:** overall band, per-criterion breakdown, feedback + anchored inline comments, late-penalty math (Epic 6.1). No `grades` table, no `POST /grade`, no `/result` frontend route (reserved for 5-5b).

## Acceptance Criteria

### A. Route, read & bootstrap (assignment-keyed, side-effect-free)

1. **Route + role-gate (renamed — D7/D12).** Given a student navigates to `/assignments/:assignmentId/submission`, When the page mounts, Then it renders as a **full-bleed sibling route** (outside `AppLayout`, like `/write`·`/speak`·`/attempt`), lazy via a **deep named import** (dedicated Rolldown chunk — `route-bundle-boundaries.spec.ts`), gated `RouteRoleGate allowedRoles={['student']}`; a teacher/owner/admin → the role-copy, the review surface **absent from the DOM** (TEST-FE-6). Component `SubmissionReviewPage`. A persistent "← Back to assignments" returns to `/assignments`. The `/assignments/:id/result` frontend route is **NOT registered** (reserved for 5-5b).
2. **Read-only bootstrap — NO write side-effect.** The page reads via `GET /api/assignments/{assignmentId}/result` (AC3), NOT `useAttemptBootstrap` (which `POST`s `/api/submissions` first — 409s on a terminal submission). A new hook `useSubmissionReview(assignmentId)` calls it via `apiFetchWithMeta`, keyed off a new `reviewKeys` factory (TS-3), `staleTime:0`, `retry:false`, unwrapping the envelope (TS-4). `meta.serverTime` anchors the read-only/late derivation (`createServerClock`, never `Date.now()` — TS-6).
3. **Backend read contract (additive; api.yaml → codegen → Go).** `GET /api/assignments/{assignmentId}/result` — **student only** (non-student → 403 `INSUFFICIENT_ROLE`). Resolves the caller's UNIQUE `(student_id, assignment_id)` submission where **`student_id` comes from the authenticated principal, never a request param** (SEC-1/GO-1). Active-enrollment re-check → 403 `NOT_ENROLLED`. No submission → **404 `SUBMISSION_NOT_FOUND`** (never a 403 existence oracle). **`in_progress` submission → 200 with a resume-CTA payload (short-circuit: NO strip, NO presign — D10)**; the page shows "not submitted yet → resume your attempt" (AC10). **NOT lock-gated** — closed/past-deadline terminal submission still returns 200 read-only. Terminal → `StudentSubmissionResult { submission (incl. submission.id — 5-5b's join key, Winston BLOCKER), assignment: StudentAssignmentView, exercise: AttemptExercise ($ref the 5.2a answer-stripped schema — no parallel type), released: false, audioUrl: string|null }`. **Both RLS reads (submission AND assignment) are tenant-scoped** (the assignment object is returned — cross-tenant assignmentId must not leak it; Murat B-2). GO-2 typed errors, GO-4 ctx, GFW-5 envelope. Reuse the shipped `assertOwnership`/`assertActiveEnrollment`/`stripAnswers` as **shared helpers** — no fork-and-edit of `GetAttemptBundle` (Winston STRONG).
4. **SEC-8 audio presign — OUTSIDE the read tx (D9/PERF-1), via `PresignGetOwned`.** For a terminal speaking submission, `audioUrl` is minted by a new atomic `StorageService.PresignGetOwned(ctx, key, tc, 5*time.Minute)` that **re-asserts `strings.HasPrefix(key, tc.CenterID+"/")` (SEC-8) then presigns a GET** (foreign prefix → 403 `R2_KEY_PREFIX_MISMATCH`; never log the URL — A10). The presign runs **after the RLS read tx commits** (never hold a PG tx across the R2 signing round-trip — PERF-1; order: `read tx → commit → PresignGetOwned → assemble`). `audioUrl` is `null` for non-speaking submissions AND for a speaking submission with no `audioKey` (**must not 500 on a nil key** — Murat B-3). `FileService.GetFileDownloadURL` is refactored to call the same primitive (de-dup the SEC-8 invariant; each caller keeps its own upstream authz — Winston STRONG).

### B. Pending identity, timing & the class-average omission (grade-independent)

5. **"Grades not released yet" — a quiet note, NOT a pending hero (D12; John BLOCKER, Sally STRONG).** The page identity is "Review my submission", not "Result — pending". A quiet secondary line "Grades not released yet — you'll be notified when your grade is ready" (with a horizon, Sally) sits near the header; the read-back is the hero. In the pre-Epic-6 world `released` is ALWAYS false — this is the baseline, not an error. 5-5b adds the grade block above the read-back when `released == true`.
6. **On-time / late badge — neutral, softened, VN-laid-out (D5; Sally STRONG).** From `submission.isLate` + `submittedAt` vs `assignment.deadlineAt`: on-time → an explicit calm "Submitted on time" (not a blank), late → "Submitted after the due date" + a quiet "Your teacher will consider this when grading" (never red/alarm — `--cl-muted`; no worst-case vacuum). **No penalty NUMBER in 5-5a** (`appliedPenalty` math → 5-5b). Badge/pills laid out at **Vietnamese length** (min-width + wrap, never a fixed-width pill that clips VN — Sally BLOCKER).
7. **No grade data ANYWHERE (grade-independent negatives).** Class/cohort average is structurally absent from the DOM (not merely hidden). Also assert **no band / no per-question score / no correctness / no released-feedback** value renders in ANY state (Murat — one leaked `data-score` passes a class-average-only test and still leaks).

### C. Own-submission read-back — the D11 playback handoff (per skill)

8. **Writing read-back.** Given a writing submission, `submission.content.text` (`{schemaVersion:1, text}` — 5.3 D1, plain text) renders **read-only, `white-space: pre-wrap`** (reuse a disabled `WritingEditorLeaf` seeded from the text, or a plain read-only block — no toolbar, no word-count, no editing).
9. **Quiz read-back — a RECEIPT, not a de-ticked scorecard (D11; Sally BLOCKER).** Given a reading/listening/vocabulary submission, the student's own answers (`content.answers`, `content.flagged` — 5.2b) render **read-only, framed in copy as "Your submitted answers — grading not released yet"**, and **visually must NOT mimic a correctness grid** (no "your answer / correct answer" columns, no checkmark-shaped whitespace). Each answer shows its **question STEM** beside it (an answer without its stem is hollow — "B _of what?_") — **gated on Task-0 T-verify that the 5.2a answer-stripped bundle retains stems**; if not, Task 1 amends the strip to retain stems (re-verify the strip test). Reuse the `disabled` `ChoiceOption`·`GapInput`·`MatchingBoard` + answered/flagged navigator; `correctAnswer`/`acceptedVariants` structurally absent (5.2a) — **assert none in the DOM** (negative). Listening SOURCE audio uses the existing `AttemptAudioPlayer` (section-URL player), distinct from the student's own recording (AC10).
10. **Speaking playback — hybrid inline + on-demand presign (D8; Winston STRONG + Sally BLOCKER).** Given a speaking submission (`content = {schemaVersion:1, audioKey, contentType, durationSec}` — 5.4), the page plays the submitted take in a native `<audio controls>` (reuse the `RecordingPreview` markup; `contentType` selects the container). **First paint** uses the inline `audioUrl` (AC4 — no extra RTT on load). On **play-intent**, if the cached URL is older than ~4 min the client fetches a fresh URL from **`GET /api/assignments/{assignmentId}/submission/audio`** (on-demand mint — same `PresignGetOwned` + ownership gate) **before** the native element can error, so the student never sees a broken control frame (Sally); a `<audio>` error is the last-resort trigger. Show **"Loading your recording…"** during the refresh; a failed mint → a **recoverable "Couldn't load your recording — tap to try again"**, never a terminal "unavailable" unless the mint itself 4xxs.
